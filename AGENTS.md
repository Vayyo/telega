# Безопасная публикация

- Исходная локальная Git-история этого проекта содержит личные сведения. Никогда не отправляй её ветки, теги или объекты на GitHub и не переноси её коммиты в публичный репозиторий через merge, cherry-pick или rebase.
- Исходный локальный клон — источник файлов, но не истории: переноси только проверенные файлы в отдельный репозиторий с чистой публичной историей. Перед push проверь staged-файлы и метаданные коммита на секреты и личные данные.
- Чистую публичную историю можно обновлять обычными коммитами после этой проверки.
