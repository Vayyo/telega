# Telega v0.4.0

Второй аудит безопасности с исправлениями, память неактивных вкладок, папки и выделение сообщений, пределы кэша.

- Прокси с логином/паролем: закреплённая TDLib пересобирается с тремя патчами — проверка сертификата и запрет HTTP-редиректов у DNS-over-HTTPS, числовые A/AAAA без системного CNAME-резолва, отдельный HTTPS-запрос A. При недоступном `dns.google` такой прокси не подключается; IP-литералы не требуют DNS.
- Границы async-ответов: поздние ответы TDLib применяются только к запустившему их клиенту; история дополнительно сверяется с окном, чатом и токеном запроса. Ошибка загрузки выгруженной вкладки лечится повторным кликом.
- Локальный пароль: минимум 12 символов для нового пароля (короткие прежние принимаются при разблокировке); ошибка удаления данных при сбросе аккаунта не стирает метаданные ключа, результат Unlock привязан к клиенту.
- Память: неактивная вкладка выгружает историю через 5 минут и восстанавливает позицию чтения повторной загрузкой; правки и удаления во время перехода к сообщению не теряются; декодированные картинки — общий бюджет 64 МиБ с истечением 5 минут.
- Интерфейс: папки в узкой левой колонке, выделение сообщений рамкой и двойным кликом, меню действий поверх истории, мини-аватарки во вкладках, портреты аккаунтов, 256 px фото профилей, кнопки ввода из графических иконок.
- Хранилище: настраиваемые пределы размера (1–100 ГиБ) и срока (1–12 месяцев) для скачанных файлов TDLib (на аккаунт) и общего кэша декодированных аватарок.
- Архив и закрепления: правка до первой записи больше не теряет локальную копию; «Закрепить здесь» хранится локально для каждого аккаунта и отдельно для ленты и архива.
- Плагины: действия привязаны к исходным аккаунту и клиенту, повторно проверяют готовность, права и dry-run; очереди, размеры значений и таймауты ограничены.

Проверено офлайн: 439 обычных тестов, 2 интеграционных теста TDLib, 4 standalone native-проверки, 27 headless-сцен sandbox, `clippy -D warnings`, `fmt --check`. Живой аккаунт, реальная сеть и сетевой посредник не использовались; нативный DoH-патч проверен статически независимым ревью. `cargo audit`/сканирование CVE не проводилось.

Это **source-only release**: `build.rs` встраивает Telegram API ID/hash, использованные при сборке; бинарник не публикуется.

Ограничения шифрования, recovery, памяти и непроверенные сценарии: [аудит 2026-10-04](https://github.com/Vayyo/telega/blob/v0.4.0/docs/security-audit-2026-10-04.md), [ADR-014](https://github.com/Vayyo/telega/blob/v0.4.0/docs/adr/014-client-bound-async-and-proxy-dns.md).
