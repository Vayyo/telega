# Telega v0.3.0

Исправления всех 14 пунктов локального security-аудита и аудиопаузы.

- Восстанавливаемая смена локального пароля: долговечный зашифрованный journal ключей, проверка архива, replay удалений, терминальный own-purge и guards смены/выхода из аккаунта. Committed rekey/purge не откатываются из-за ошибки checkpoint/VACUUM.
- Lua-действия привязаны к исходным account/client и повторно проверяют Ready, enabled, permissions и dry-run. Очереди ограничены; policy/account/FloodWait имеют приоритет.
- Observer очищает отменённые запросы; malformed native ответы не паникуют и не попадают raw payload в предупреждения. FileStream корректно обрабатывает ошибки, остановку, отсутствие прогресса и неизвестный размер.
- Нативные animation/photo workers удерживают permit до фактического выхода. Пароли, ключи, scratch Argon2 и принадлежащие Rust секретные wire-буферы используют очищаемое владение.
- Ссылки под спойлером проверяются по реально видимому тексту; multiline code-span не копируется на каждую строку. Пауза аудио больше не расходует PCM-очередь.

Проверено офлайн: 46 security-регрессий, 384 обычных теста, 2 локальных TDLib integration-теста, 4 standalone native проверки, input/Lua-пробы и headless password/menu. Security-регрессии входят в число обычных тестов, не прибавляются к нему.

Это **source-only release**. Локальный бинарник не публикуется: `build.rs` встраивает Telegram API ID/hash, использованные при сборке. Для собственной сборки нужны свои ключи и native-зависимости из README. Никаких `.env`, каталога данных аккаунта или исходной частной Git-истории в публикацию не переносится.

Ограничения шифрования, recovery, памяти и проверки: [описание исправлений](https://github.com/Vayyo/telega/blob/v0.3.0/docs/security-fixes-2026-10-02.md). Физический сбой питания, реальный Telegram-аккаунт и полный fuzz нативных библиотек не проверялись; релиз не является сертификатом безопасности.
