# 007. Видеокружочки в общем плеере и громкость на сообщение

Дата: 2026-10-01

## Решение

`messageVideoNote` открывается по нажатию в том же видеоплеере, что и обычное видео: пауза, перемотка, ползунок громкости, выключение звука и раскрытие поверх окна. В ленте кадр и фон плеера остаются круглыми; в раскрытом режиме кадр показывается целиком. Анимированные GIF остаются в прежнем циклическом воспроизведении без видеоконтролов.

Громкость (0–100%) и последнее ненулевое значение для возврата после выключения звука хранятся в `settings.json` по слоту аккаунта, ID чата и ID сообщения. Другие сообщения, даже с тем же файлом, имеют независимую громкость. Новый ролик начинает с 100%; изменение ползунка действует сразу, а сохраняется при отпускании, выключение звука — сразу. Перед закрытием или сменой видео/аккаунта текущее значение сохраняется. При редактировании сообщения, заменившем исходный файл, прежний плеер останавливается; настройка остаётся привязанной к сообщению. Отсутствующее поле в прежних настройках получает значение по умолчанию.

## Почему

Общий плеер уже реализует потоковую загрузку, перемотку и раскрытие. Отдельная ветка для кружочков через анимированные кадры дублировала бы управление и не давала бы управлять звуком. ID файла нельзя использовать как ключ громкости: несколько сообщений могут ссылаться на один файл, но требовать разных уровней.

## Отвергнутые альтернативы

- Общая громкость для всех видео: не выполняет требование отдельной настройки для каждого ролика.
- Привязка громкости к ID файла: связывает два разных сообщения при повторной отправке одного файла.
- Второй плеер специально для кружочков: дублирует потоковое воспроизведение и состояние управления.

## Следствия

- Настройки добавляются только для сообщений, громкость которых менялась; при выходе из аккаунта они удаляются вместе с его записью. Карта настроек не очищается отдельно при удалении сообщения.
- Раскрытие использует существующий оверлей окна, а не переключает оконный менеджер в системный полноэкранный режим.
