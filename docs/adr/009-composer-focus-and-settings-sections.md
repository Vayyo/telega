# 009. Фокус ввода, полупрозрачное меню и категории настроек

Дата: 2026-10-01

Решение: после выбора чата и закрытия перекрывающей панели немедленно возвращать фокус редактору сообщения через операцию, ограниченную корнем конкретного окна. Поиск и модальные панели блокируют ввод в черновик; обычная боковая панель профиля и выбор сообщений не блокируют. Полупрозрачность применяется только к фону меню из ADR-004, а не к тексту и кнопкам. Настройки раскрываются по независимым категориям с состоянием в текущей сессии аккаунта.

Почему: ожидание ответов TDLib не должно задерживать ввод; стандартная операция фокуса iced снимает фокус с других окон, если не ограничить обход. Прозрачность всего виджета ухудшает читаемость. Категории сокращают одновременно видимый список параметров без удаления функций.

Отвергнутые альтернативы: фокусировать редактор при каждом обновлении — перехватывает поиск и мешает курсору; ждать сетевые задачи — ввод зависит от сети; хранить раскрытие на диске — ненужное изменение формата настроек; разрешать только одну открытую категорию — мешает сравнивать параметры.

Следствия: редактор сохраняет читаемый текст при блокировке; переходы фокуса не меняют черновики, Enter и Shift+Enter. Категории изначально свёрнуты, их состояние сохраняется при закрытии настроек и просмотре справки плагинов, сбрасывается при новой сессии аккаунта.
