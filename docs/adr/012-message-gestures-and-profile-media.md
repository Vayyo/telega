# 012. Жесты сообщений и качественное медиа профиля

Дата: 2026-10-02.
Решение: рамка ЛКМ начинается на свободном фоне истории и пересекает реальные bounds пузырей; двойной клик завершается ответом только после второго release без drag. Действия выделенного набора открываются ПКМ отдельным слоем по ADR-004. GIF сохраняют намерение при занятых декодерах; явный клик уступает один автоматический поток и получает приоритет после реального освобождения permit. Профили используют большой файл TDLib и отдельный ленивый 256 px кэш из 32 записей.
Почему: перетаскивание текста и интерактивные элементы должны сохранять прежнее поведение; меню не должно менять высоты истории; занятый слот не означает потерю запроса; увеличение 64 px картинки размывает профиль.
Отвергнутые альтернативы: выбор сообщений вместо выделения текста, ответ на второй press до release, автоматическое открытие действий, внешняя программа для GIF, снятие трёхпоточного native-лимита, увеличение всех аватарок и изменение формата дискового кэша.
Следствия: готовые большие GIF не ограничены порогом автоматической загрузки; новая автоматическая загрузка сохраняет 10/1 МиБ ограничения. Permit остаётся у native/blocking worker до его выхода; готовые ожидающие GIF проверяются существующим 150 ms tick. 64 px дисковый кэш и фотографии аккаунтов совместимы. Уже запрошенное HD-декодирование может завершиться после закрытия профиля и прогреть ограниченный кэш; результаты прежнего клиента и удалённой привязки не показываются.
